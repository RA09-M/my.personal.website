ROSE ANN PERSONAL WEBSITE

1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html.
4. For the easiest preview, install the "Live Server" extension in VS Code and choose "Go Live".
5. Your profile photo is in assets/Profile.jpeg.
6. Your CV is included as RoseAnn_Mariscotes_CV.docx.

The site is responsive and includes:
- Modern portfolio layout
- Profile photo
- Download CV buttons
- Dark/light mode
- Mobile navigation
- Animated section reveals
- About, skills, experience, education and contact sections
